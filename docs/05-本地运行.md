# 05 · 本地运行步骤

> 目标：从一台只有 JDK 和 MySQL 的电脑开始，把 5 个接口跑通。
> 命令按 Windows PowerShell 写，macOS / Linux 的差异会单独标注。

## 0. 三步速通

```bash
# 1. 建库建表
mysql -u root -p -e "source sql/01_create_database.sql"
mysql -u root -p task_manager -e "source sql/02_create_table.sql"

# 2. 启动
./mvnw spring-boot:run          # macOS/Linux
.\mvnw.cmd spring-boot:run      # Windows

# 3. 验证
curl http://localhost:8080/api/tasks
```

下面解释每一步在做什么，以及报错怎么办。

---

## 1. 检查环境

### 1.1 Java 17+

```bash
java -version
```

要求 ≥ 17。没有的话装 JDK 21（LTS）：<https://adoptium.net/>

### 1.2 MySQL

```bash
mysql --version
```

Windows 上若提示找不到命令，把 `bin` 目录加进 `PATH`，例如：

```text
C:\Program Files\MySQL\MySQL Server 5.7\bin
```

确认服务在跑：

```powershell
Get-Service MySQL57          # Windows
```

```bash
sudo systemctl status mysql  # Linux
```

### 1.3 Maven 不用装

项目自带 Wrapper。第一次执行会自动下载 Maven 3.9.11：

```bash
.\mvnw.cmd -v     # Windows
./mvnw -v         # macOS/Linux
```

> Windows 如果提示「禁止运行脚本」，用 `.\mvnw.cmd`，不要用 `.\mvnw`。

## 2. 建库、建表

在**项目根目录**执行：

```bash
mysql -u root -p -e "source sql/01_create_database.sql"
mysql -u root -p task_manager -e "source sql/02_create_table.sql"
```

会提示输入 root 密码（输入时不显示字符，正常）。

这两条脚本做了：

| 脚本 | 做的事 |
|---|---|
| `01_create_database.sql` | 建 `task_manager` 库（utf8mb4）+ 建 `task_app` 账号并授权 |
| `02_create_table.sql` | 建 `task` 表 + 两个索引 |

### 验证建表成功

```bash
mysql -u task_app -p task_manager -e "SHOW TABLES; DESC task;"
```

密码：`TaskApp@123456`

预期：

```text
+------------------------+
| Tables_in_task_manager |
+------------------------+
| task                   |
+------------------------+

+------------+--------------+------+-----+----------------------+----------------+
| Field      | Type         | Null | Key | Default              | Extra          |
+------------+--------------+------+-----+----------------------+----------------+
| id         | bigint(20)   | NO   | PRI | NULL                 | auto_increment |
| title      | varchar(200) | NO   |     | NULL                 |                |
| status     | varchar(20)  | NO   | MUL | TODO                 |                |
| created_at | datetime(6)  | NO   | MUL | CURRENT_TIMESTAMP(6) |                |
+------------+--------------+------+-----+----------------------+----------------+
```

### 用图形界面也行

MySQL Workbench：`File → Open SQL Script`，依次执行两个脚本，刷新左侧 `SCHEMAS`。

## 3. 数据库配置

配置文件：`src/main/resources/application.yml`

```yaml
spring:
  datasource:
    url: "${DB_URL:jdbc:mysql://localhost:3306/task_manager?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true}"
    username: "${DB_USERNAME:task_app}"
    password: "${DB_PASSWORD:TaskApp@123456}"
    driver-class-name: com.mysql.cj.jdbc.Driver

  jpa:
    hibernate:
      ddl-auto: none      # 表由 SQL 脚本建，Hibernate 不插手
    show-sql: true
    properties:
      hibernate:
        format_sql: true
```

`${DB_URL:默认值}` 的含义：有环境变量就用环境变量，没有就用冒号后面的默认值。

### 我的账号密码不一样，怎么改

**方式一：改文件**（最简单）

把 `username` / `password` 改成你的，同时把 `sql/01_create_database.sql` 里的密码也改掉，重新执行建库脚本。

**方式二：环境变量**（推荐，不把密码写进文件）

Windows PowerShell：

```powershell
$env:DB_USERNAME = "task_app"
$env:DB_PASSWORD = "你的密码"
$env:DB_URL = "jdbc:mysql://localhost:3306/task_manager?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true"

.\mvnw.cmd spring-boot:run
```

macOS / Linux：

```bash
export DB_USERNAME=task_app
export DB_PASSWORD='你的密码'
export DB_URL='jdbc:mysql://localhost:3306/task_manager?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true'

./mvnw spring-boot:run
```

环境变量只在当前窗口有效，关掉就失效。

## 4. 启动

```bash
.\mvnw.cmd spring-boot:run      # Windows
./mvnw spring-boot:run          # macOS/Linux
```

第一次会下载依赖，1～5 分钟。成功的标志：

```text
Tomcat started on port 8080 (http)
Started TaskManagerApplication in 2.901 seconds
```

常见但**不是错误**的日志：

```text
WARN ... The 5.7.29 version for [MySQLDialect] is no longer supported
```

这是 Hibernate 6.6 对 MySQL 5.7 的提示。实测接口全部正常，学习可以继续用；正式项目建议 MySQL 8.0+。

### 验证

浏览器或命令行访问：

```bash
curl http://localhost:8080/api/tasks
```

空库返回：

```json
[]
```

### 停止

在运行窗口按 `Ctrl + C`。

## 5. 调用接口

推荐顺序：新增 → 查全部 → 查单个 → 更新 → 删除。

### 5.1 Postman

1. `Import` 两个文件：
   - `postman/Task-API.postman_collection.json`
   - `postman/Task-API.postman_environment.json`
2. 右上角选环境「任务清单-本地环境」
3. 按 `01 → 07` 顺序点 `Send`，或点集合 `Run` 一次跑完

预期：7 个请求、17 个断言、0 失败。

### 5.2 命令行

```bash
# 新增
curl -X POST http://localhost:8080/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"学习 Spring Boot","status":"TODO"}'

# 查全部
curl http://localhost:8080/api/tasks

# 查单个（把 1 换成真实 id）
curl http://localhost:8080/api/tasks/1

# 更新
curl -X PUT http://localhost:8080/api/tasks/1 \
  -H "Content-Type: application/json" \
  -d '{"title":"学习 Spring Boot（完成）","status":"DONE"}'

# 删除
curl -X DELETE http://localhost:8080/api/tasks/1
```

完整参数说明见 [04-接口文档](04-接口文档.md)。

### 5.3 自动测试

项目自带 9 个场景的冒烟测试（需要 Node.js 18+）：

```bash
node scripts/api-smoke-test.mjs
```

预期输出：

```text
✅ 01 新增任务 A（默认状态 TODO）  [HTTP 201]
...
测试完成：9/9 通过，0 失败
```

## 7. 常见报错排查

### `Port 8080 was already in use`

端口被占。找占用进程：

```powershell
Get-NetTCPConnection -LocalPort 8080 -State Listen    # Windows
lsof -i :8080                                         # macOS/Linux
```

要么关掉，要么换端口：

```powershell
$env:SERVER_PORT = "9090"
```

> 这个坑我踩过两次：上一次启动的 Java 进程没关干净，再次启动就报这个。

### `Access denied for user 'task_app'@'localhost'`

账号或密码不对。重跑建库脚本，或检查 `application.yml` 是否与 SQL 脚本一致。

### `Unknown database 'task_manager'`

没建库，执行 `01_create_database.sql`。

### `Table 'task_manager.task' doesn't exist`

没建表，执行 `02_create_table.sql`。

### `Communications link failure`

MySQL 没启动：

```powershell
Start-Service MySQL57     # Windows
```

```bash
sudo systemctl start mysql # Linux
```

### 中文乱码

按顺序查：

1. 库和表是 `utf8mb4`
2. 请求头 `Content-Type: application/json; charset=utf-8`
3. PowerShell 里发中文，用「转 UTF-8 字节」的写法，或直接用 Postman
4. 终端本身的编码（`chcp 65001`）

### 第一次构建特别慢

在下载 Maven 和依赖，正常。下载完会缓存到 `~/.m2`，之后很快。

## 8. 最短复查清单

跑通后，以后每次改完代码，按这个清单自查：

- [ ] `mvnw clean package` 能编译
- [ ] 启动日志有 `Started TaskManagerApplication`
- [ ] `curl /api/tasks` 返回 200
- [ ] Postman 集合 Run 一遍，17 个断言全绿
- [ ] 数据库里确实有数据（`SELECT * FROM task;`）
