# 04 · 接口文档

> 5 个 REST 接口的完整说明：请求方式、路径、入参、出参、状态码、错误格式。

## 1. 基本信息

| 项目 | 值 |
|---|---|
| 本地地址 | `http://localhost:8080` |
| 接口前缀 | `/api/tasks` |
| 请求体格式 | `application/json`（UTF-8） |
| 响应体格式 | `application/json`（UTF-8） |
| 时间格式 | `yyyy-MM-dd HH:mm:ss` |
| 认证 | 无（学习项目） |

### 状态枚举

| 值 | 含义 |
|---|---|
| `TODO` | 待办 |
| `IN_PROGRESS` | 进行中 |
| `DONE` | 已完成 |

### 接口一览

| # | 功能 | 方法 | 路径 | 成功状态码 |
|---|---|---|---|---|
| 1 | 新增任务 | `POST` | `/api/tasks` | `201 Created` |
| 2 | 查询全部 | `GET` | `/api/tasks` | `200 OK` |
| 3 | 查询单个 | `GET` | `/api/tasks/{id}` | `200 OK` |
| 4 | 更新任务 | `PUT` | `/api/tasks/{id}` | `200 OK` |
| 5 | 删除任务 | `DELETE` | `/api/tasks/{id}` | `204 No Content` |

## 2. 新增任务

### 请求

```http
POST /api/tasks
Content-Type: application/json
```

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `title` | Body | string | 是 | 任务标题，1～200 字符，不能全是空格 |
| `status` | Body | string | 否 | `TODO` / `IN_PROGRESS` / `DONE`，不传默认 `TODO` |

```json
{
  "title": "学习 Spring Boot 增删改查",
  "status": "TODO"
}
```

### 成功响应 `201 Created`

响应头：

```text
Location: http://localhost:8080/api/tasks/1
```

响应体：

```json
{
  "id": 1,
  "title": "学习 Spring Boot 增删改查",
  "status": "TODO",
  "createdAt": "2026-10-20 15:23:41"
}
```

### 失败响应

| 场景 | 状态码 | 说明 |
|---|---|---|
| `title` 为空 | `400` | `fieldErrors.title = 标题不能为空` |
| `title` 超 200 字符 | `400` | `fieldErrors.title = 标题不能超过 200 个字符` |
| `status` 不是枚举值 | `400` | 提示只能用三个值 |
| JSON 格式错误 | `400` | 请求体解析失败 |

## 3. 查询全部任务

### 请求

```http
GET /api/tasks
```

无参数。

### 成功响应 `200 OK`

```json
[
  {
    "id": 2,
    "title": "整理接口测试记录",
    "status": "IN_PROGRESS",
    "createdAt": "2026-10-20 15:23:41"
  },
  {
    "id": 1,
    "title": "学习 Spring Boot 增删改查",
    "status": "TODO",
    "createdAt": "2026-10-20 15:23:41"
  }
]
```

空库时返回：

```json
[]
```

### 排序规则

按 `createdAt` 倒序；创建时间相同时按 `id` 倒序。最新的任务排最前面。

## 4. 查询单个任务

### 请求

```http
GET /api/tasks/{id}
```

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `id` | Path | long | 是 | 任务 id |

### 成功响应 `200 OK`

```json
{
  "id": 1,
  "title": "学习 Spring Boot 增删改查",
  "status": "TODO",
  "createdAt": "2026-10-20 15:23:41"
}
```

### 失败响应

| 场景 | 状态码 |
|---|---|
| id 不存在 | `404` |
| id 不是数字（如 `/api/tasks/abc`） | `400` |

## 5. 更新任务

### 请求

```http
PUT /api/tasks/{id}
Content-Type: application/json
```

| 参数 | 位置 | 类型 | 必填 | 说明 |
|---|---|---|---|---|
| `id` | Path | long | 是 | 任务 id |
| `title` | Body | string | 是 | 新标题 |
| `status` | Body | string | 是 | 新状态 |

```json
{
  "title": "学习 Spring Boot 增删改查（已完成）",
  "status": "DONE"
}
```

> `PUT` 表示**整体更新**，所以 `title` 和 `status` 都必须传。
> 只想改状态也要把原标题带上，否则会返回 `400`。

### 成功响应 `200 OK`

```json
{
  "id": 1,
  "title": "学习 Spring Boot 增删改查（已完成）",
  "status": "DONE",
  "createdAt": "2026-10-20 15:23:41"
}
```

`createdAt` 保持不变（实体上标了 `updatable = false`）。

### 失败响应

| 场景 | 状态码 |
|---|---|
| id 不存在 | `404` |
| `title` 为空 / 超长 | `400` |
| `status` 缺失或非法 | `400` |

## 7. 统一错误格式

所有错误都由 `GlobalExceptionHandler` 转成同一种结构：

```json
{
  "timestamp": "2026-10-20 15:23:41",
  "status": 404,
  "error": "Not Found",
  "message": "任务不存在，id=1",
  "path": "/api/tasks/1",
  "fieldErrors": {
    "title": "标题不能为空"
  }
}
```

| 字段 | 说明 |
|---|---|
| `timestamp` | 出错时间 |
| `status` | HTTP 状态码 |
| `error` | 状态短语 |
| `message` | 可读的中文说明 |
| `path` | 请求路径 |
| `fieldErrors` | 仅参数校验失败时出现，字段名 → 错误信息 |

### 各状态码对应场景

| 状态码 | 场景 |
|---|---|
| `200` | 查询、更新成功 |
| `201` | 新增成功 |
| `204` | 删除成功 |
| `400` | 参数校验失败 / JSON 非法 / id 非数字 |
| `404` | 任务不存在 |
| `500` | 未预期的服务器异常（看后端日志） |

## 8. 调用示例

### 8.1 Postman

1. 导入 `postman/Task-API.postman_collection.json`
2. 导入 `postman/Task-API.postman_environment.json`
3. 右上角选择环境「任务清单-本地环境」
4. 按 `01 → 07` 顺序运行，或点集合右侧 `Run`

集合里第一个请求会自动把新任务 id 存进 `taskId` 变量，后续请求自动复用。

### 8.2 curl

```bash
# 新增
curl -i -X POST http://localhost:8080/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title":"学习 Spring Boot","status":"TODO"}'

# 查全部
curl http://localhost:8080/api/tasks

# 查单个
curl http://localhost:8080/api/tasks/1

# 更新
curl -i -X PUT http://localhost:8080/api/tasks/1 \
  -H "Content-Type: application/json" \
  -d '{"title":"学习 Spring Boot（完成）","status":"DONE"}'

# 删除
curl -i -X DELETE http://localhost:8080/api/tasks/1
```

### 8.3 PowerShell

PowerShell 直接传中文容易乱码，推荐先把 JSON 转成 UTF-8 字节：

```powershell
$body = @{ title = "学习 Spring Boot"; status = "TODO" } | ConvertTo-Json
$bytes = [System.Text.Encoding]::UTF8.GetBytes($body)

Invoke-RestMethod -Method Post `
  -Uri "http://localhost:8080/api/tasks" `
  -ContentType "application/json; charset=utf-8" `
  -Body $bytes
```

> 这是实际踩过的坑：用 `curl.exe` 在 PowerShell 里拼 `-d "{\"title\":\"中文\"}"`，双引号会被 PowerShell 吃掉，后端收到非法 JSON，返回 `400`。
